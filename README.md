# ZenHR — نظام إدارة الموارد البشرية

واجهة تجريبية عربية لإدارة الموارد البشرية مبنية باستخدام React وTypeScript وVite.

## المميزات الحالية
- لوحة تحكم بملخص الموظفين والحضور وطلبات الإجازات.
- دليل الموظفين مع البحث وإضافة موظف وحذف موظف.
- سجل حضور تجريبي.
- قبول ورفض طلبات الإجازات.
- تقارير مبسطة عن الموظفين والأقسام والرواتب.
- إعدادات اللغة والمظهر الداكن.
- تصدير نسخة JSON من بيانات الموظفين والإجازات.
- حفظ تغييرات الموظفين والإجازات محليًا عبر localStorage.
- تصميم متجاوب RTL مناسب للموبايل والكمبيوتر.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## نشر GitHub Pages
المستودع يحتوي workflow في `.github/workflows/deploy.yml` للنشر باستخدام GitHub Actions. من إعدادات المستودع اختر **Settings → Pages → Build and deployment → GitHub Actions**.

## ملاحظات مهمة
هذا نموذج أولي ببيانات تجريبية وليس نظام HR إنتاجيًا. لا يتصل بخادم أو قاعدة بيانات سحابية؛ البيانات التي تضيفها تحفظ في المتصفح الحالي فقط. لا تستخدمه لحفظ بيانات موظفين حقيقية أو حساسة قبل إضافة تسجيل دخول وصلاحيات وأمان وتخزين مناسبين.
