# ZenHR Local — مشروع إدارة الموارد البشرية

هذا المشروع نقطة بداية عربية لنظام إدارة موارد بشرية بواجهة React + Vite + TypeScript، مع بيانات وهمية ومصادقة تجريبية وحفظ محلي في المتصفح فقط.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محليًا
```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

## حسابات العرض
كلمة المرور لجميع الحسابات: `123456`
- `admin@hr.app` — مدير النظام
- `hr@hr.app` — مسؤول الموارد البشرية
- `manager@hr.app` — مدير
- `employee@hr.app` — موظف

## الرفع إلى GitHub
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات المشروع الموجودة في هذا المجلد إلى جذر المستودع، وليس ملف ZIP فقط.
3. افتح `vite.config.ts` وغيّر `base` إلى اسم المستودع، مثل:
   `base: '/اسم-المستودع/'`
4. من إعدادات المستودع افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر.
5. ادفع الملفات إلى فرع `main` وانتظر انتهاء Workflow النشر.

## تنبيه
المصادقة والبيانات تجريبية فقط. لا تستخدم هذا الإصدار لحفظ بيانات موظفين حقيقية أو حساسة. `localStorage` خاص بالمتصفح والجهاز الحاليين، ولا يزامن البيانات بين الأجهزة.
