# ZenHR — تطبيق إدارة الموارد البشرية (Static)

تطبيق ويب عربي مبني بملفات HTML وCSS وJavaScript عادي، من دون React أو TypeScript أو خطوة بناء npm.

## الملفات
- `index.html`: صفحة التطبيق.
- `css/style.css`: التصميم المتجاوب RTL.
- `js/app.js`: التنقل وعرض الصفحات والتفاعلات.
- `js/storage.js`: بيانات تجريبية وحفظ محلي في localStorage.
- `js/employees.js`: إدارة الموظفين والبحث.
- `js/attendance.js`: بيانات ملخص الحضور.
- `js/leaves.js`: طلبات الإجازة والموافقات.
- `js/reports.js`: حسابات التقارير.
- `.github/workflows/deploy.yml`: نشر الملفات الثابتة على GitHub Pages.

## النشر
من إعدادات المستودع افتح Settings → Pages واجعل Build and deployment من GitHub Actions. سير العمل ينشر ملفات HTML وCSS وJS مباشرةً ولا يحتاج npm.

## ملاحظات
- بيانات العرض تجريبية وتُحفظ على الجهاز الحالي في localStorage فقط.
- لا يوجد خادم أو قاعدة بيانات سحابية.
- زر تغيير اللغة تجريبي جزئي؛ بعض محتوى البيانات يبقى عربيًا.
- هذه نسخة أولية وليست مناسبة لبيانات الموظفين الحساسة أو للاستخدام المؤسسي قبل إضافة المصادقة والصلاحيات والنسخ الاحتياطي الآمن.
