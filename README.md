# ZenHR — نظام إدارة الموارد البشرية

تطبيق ويب عربي باتجاه RTL مبني باستخدام HTML وCSS وJavaScript عادي، ومهيأ للعمل كتطبيق ويب تقدمي PWA عبر GitHub Pages دون خادم أو خطوة بناء.

## هيكل المشروع

- `index.html`: واجهة التطبيق ونقاط تحميل ملفات JavaScript.
- `css/style.css`: التصميم المتجاوب.
- `manifest.json`: إعدادات التثبيت كتطبيق.
- `sw.js`: التخزين المؤقت الأساسي للعمل دون اتصال بعد أول زيارة.
- `js/app.js`: منطق الواجهة الحالي.
- `js/storage.js`: التخزين المحلي الحالي.
- `js/router.js`: التنقل بين الصفحات.
- `js/auth.js`: هوية محلية تجريبية فقط، وليست مصادقة آمنة.
- `js/ui.js`: رسائل الواجهة ومساعدة عرض النصوص.
- `js/utils.js`: أدوات عامة للتواريخ والعملات والتنزيل.
- `js/modules/`: وحدات الموظفين والحضور والإجازات والرواتب والمكافآت والخصومات والورديات والأقسام وتقييم الأداء والتوظيف والتقارير.
- `js/services/export.js`: تصدير CSV وJSON.
- `js/services/backup.js`: تنزيل نسخة احتياطية واستعادتها محليًا.
- `.github/workflows/deploy.yml`: نشر GitHub Pages.

## النشر

من إعدادات المستودع اختر **Settings → Pages** واجعل مصدر النشر **GitHub Actions**. لا يحتاج المشروع إلى npm أو خادم.

## الخصوصية وحدود النسخة الحالية

- البيانات التجريبية تُحفظ محليًا في المتصفح، ولا توجد قاعدة بيانات سحابية مضافة.
- ملفات الوحدات الجديدة توفر وظائف أساسية مستقلة، ولا يعني وجودها أن جميعها أصبحت مرتبطة بكل الشاشات الحالية.
- المصادقة المحلية ليست وسيلة حماية للبيانات. لا تستخدم بيانات موظفين حساسة أو معلومات رواتب حقيقية قبل إضافة صلاحيات ومراجعة أمنية مناسبة.
- النسخ الاحتياطي المحلي غير مشفر؛ احتفظ بالملف في مكان آمن.
- التخزين المؤقت للعمل دون اتصال يكتمل تدريجيًا بعد زيارة التطبيق لأول مرة.
